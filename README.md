# Android Calculator App

A simple, responsive Android calculator application built with Kotlin and XML.

## Features
- **Basic Arithmetic**: Addition, Subtraction, Multiplication, and Division.
- **Input Validation**: Prevents crashes from empty inputs.
- **Zero Division Protection**: Shows a toast message when attempting to divide by zero.
- **Responsive UI**: Material Design components with a layout that matches the provided design specifications.

## How to Run
1. Clone the repository.
2. Open in Android Studio.
3. Build and Run on an emulator or physical device.
